Guia prático

Publique este projeto no GitHub

Siga os passos na ordem. Toque em Copiar em cada comando e cole no seu terminal (Git Bash no Windows).

⚙️

Antes de começar: confira se o Git está instalado com git --version e se você já configurou seu nome e e-mail (veja a seção 03 da apostila).

1

Inicializar o repositório

Cria a pasta oculta .git e começa a monitorar os arquivos.

git init
2

Conferir o estado

Mostra os arquivos novos ou alterados que ainda não foram salvos.

git status
3

Adicionar tudo à preparação

Coloca todas as modificações na Staging Area, prontas para o commit.

git add .
4

Salvar a primeira versão (commit)

Registra um snapshot com uma mensagem clara descrevendo a alteração.

git commit -m "Adiciona apostila de controle de versão"
5

Definir a ramificação principal

Renomeia a branch atual para main — o padrão do GitHub.

git branch -M main
6

Conectar ao repositório remoto

No GitHub, crie um repositório com New, copie a URL e cole no lugar de SEU-USUARIO.

git remote add origin https://github.com/SEU-USUARIO/apostila-git.git
7

Enviar para a nuvem (push)

Publica seus arquivos e todo o histórico no GitHub. Autentique com token ou SSH.

git push -u origin main
🚀

Pronto! Atualize a página do seu repositório no GitHub — os arquivos estarão lá. A cada nova mudança, repita apenas add → commit → push.

Bônus · publicar como site (GitHub Pages)

No repositório, vá em Settings › Pages, escolha a branch main e salve. Em alguns instantes sua apostila fica no ar num endereço público https://seu-usuario.github.io/apostila-git/.
