## Como fazer um Pull Request?
(Siga esse tutorial depois de configurar seu email e nome no github... [As instruções estão na apostila](https://github.com/marcelomacrinoanchieta/aulagit/tree/main/apostila-git/apostila-git))
1. Baixe o repositório usando o comando
```sh
git clone https://github.com/marcelomacrinoanchieta/aulagit
```
2. Selecione a pasta
```sh
cd aulagit
```
3. Entra no VSCode
```sh
code .
```
4. No VSCode, clique no arquivo `README.md` e adicione seu nome no topo desse arquivo
5. Clique no símbolo de **Source Control** (abaixo da lupa na esquerda)
6. Clique em **Manage Workspace Trust** e depois em **Trust**
7. Feito isso, aparecerá um botão de "Commit". Clique nesse botão.
8. Clique em **yes** e escreva uma mensagem na primeira linha descrevendo o que você mudou. Seja breve e escreva no imperativo (por questões de padronização), como: "Adiciona nova participação"
<br><img width="609" height="195" alt="image" src="https://github.com/user-attachments/assets/785b178e-ed68-4e49-85f4-35b59547aa82" />
9. Clique no botão commit flutuante
10. Clique em "Sync"
11. Será solicitado que você logue no seu Github. Logue.
12. O programa perguntará se você quer criar um "fork". Aceite.
13. Volte no navegador, entre no seu perfil do github e clique no repositório novo que apareceu na sua lista de repositório.
14. Lá, clique em "Contribute" e depois em "Open pull pequest"
15. Dê um título para sua solicitação e pronto!

## O que é esse arquivo?

O README.md é um arquivo especial feito em MARDOWN (uma linguagem de marcação de texto leve). Ele é especial porque quando colocado em alguma pasta no seu projeto, aparece no Github como um tipo de "descrição longa", logo abaixo do explorador de arquivos.

.md significa Markdown. Como uma linguagem de marcação de texto, você pode usá-la para "formatar" seus textos. Ela aceita tanto a sintaxe própria quanto HTML
Se quiser aprender um pouco sobre a sintaxe do markdown, clique aqui - https://docs.github.com/pt/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
